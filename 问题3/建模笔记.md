# 问题 3 建模笔记

## 1. 问题目标

每天0:00依据当时发布的未来24小时光伏预报制定144个10分钟时段的原计划购电量；6:00、12:00、18:00依据新预报和当前实际SOC，只调整尚未执行的时段。总费用包括原计划购电费、调整结算费用和五倍电价的紧急购电费。

## 2. 当前时刻可用信息

- 电价取附件1的固定日内电价；
- 负载预测只使用目标日之前已经完成的附件2历史负载；
- 光伏预测使用附件3在当前时刻已经发布的未来24小时预报；
- 当天未来实际负载和实际光伏只用于历史回测，不能进入提前决策；
- 6:00、12:00、18:00发布的预报分别最早作用于slot=36、72、108；过去的购电量、充放电量和SOC全部固定。

## 3. 数据、时间与单位

统一读取`公共代码/数据/master_10min.csv`和`forecast_attachment3_hourly.csv`。每天144个时段，slot=0为00:00—00:10，slot=143为23:50—24:00。附件3的“预报h小时”表示发布时间+h小时。

功率变量使用kW，时间步长Δt=1/6小时，电量和SOC使用kWh。Excel输出的购电、充电和放电量均由功率乘Δt得到。模板计划时段文字整体比内部物理区间晚10分钟，保留原表头并按slot位置写入；论文按内部物理区间取值。

## 4. 参数和变量

储能参数：1200≤S≤10800 kWh，初始时刻S=6000 kWh，充放电功率上限均为5000 kW，充放电效率均为0.9。

变量包括原计划购电功率q_plan、最终调整购电功率q_adj、充电功率c、放电功率d、紧急购电功率e、未利用富余功率w、边界SOC S和充放电模式z。每个时段z为二元变量，保证充放电互斥。

## 5. 预测与插值

附件3每次发布24个整点目标功率。以发布时间处已经可测的光伏功率为起点，与发布时间+1至+24小时的预报点做分段线性插值，在每个10分钟区间结束时刻取值。0:00发布的预报覆盖当天全部时段；后续预报只使用至当天24:00的部分。

负载预测为最近W个已完成日期同期负载的α经验分位数。1月1日无历史时采用零负载预测作为冷启动；1月运行使用预先固定的W=14、α=0.8。以1月15—31日为虚拟顺序验证期，在W∈{7,14,28}、α∈{0.50,0.65,0.80,0.90,0.95}中按“总费用+期末库存折算”选择参数，得到W=14、α=0.65，并于2月1日冻结。

## 6. 计划和调整费用

0:00原计划目标：

    min Σ π[t] q_plan[t] Δt

调整结算采用以下解释：原计划费先全额计入；减少计划量的部分按原价50%退回，增加部分按原价1.5倍补计。因此：

    C_adjust = Σ {1.5π[t](q_adj[t]-q_plan[t])_+
                  -0.5π[t](q_plan[t]-q_adj[t])_+} Δt

调整模型只最小化尚未执行时段的C_adjust，原计划费是沉没成本。该函数为斜率从0.5π增加到1.5π的凸分段线性函数，代码使用上界变量精确线性化。后续每次调整均与当天0:00原计划比较，避免重复结算同一偏差。

    C_plan = Σ π[t] q_plan[t] Δt
    C_emergency = Σ 5π[t] e[t] Δt
    C_total = C_plan + C_adjust + C_emergency

`result3.xlsx`的“计划购电量”全天费用为C_plan；“调整购电量”全天费用为C_plan+C_adjust，不含紧急购电费。

## 7. MPC约束与实际执行

每次计划或调整对剩余时段求解：

    q[t] + d[t] - c[t] >= load_forecast[t] - pv_forecast[t]
    S[t+1] = S[t] + 0.9 c[t] Δt - d[t] Δt/0.9
    1200 <= S[t] <= 10800
    0 <= c[t] <= 5000 z[t]
    0 <= d[t] <= 5000(1-z[t]), z[t]∈{0,1}
    S[0] = 当前实际SOC，S[末] = 6000

末端6000 kWh是有限时域储备假设，只约束预测轨迹，不强制实际日末SOC等于6000。实际执行固定当前有效购电量；富余时在约束内充电，缺口时先放电，再以紧急购电补足，未利用富余记为w：

    q_adj + e + PV_actual + d = load_actual + c + w

实际日末SOC直接作为下一日0:00初始SOC，全年连续递推。

## 8. 求解方法

`代码/solve_q3.py`使用SciPy HiGHS MILP，相对间隙阈值1e-9，单次时限30秒。0:00求解全天计划；6:00、12:00、18:00从实际SOC重新求解剩余时域。求解失败立即终止。

`代码/export_q3.mjs`使用`@oai/artifact-tool`填充附件5原模板并渲染检查；`代码/report_q3.py`生成论文表格；`代码/verify_q3.py`独立核对原附件、单位、物理约束、信息边界、费用、事件合并和Excel。

## 9. 主要结果

2—12月原计划购电量23417901.9711 kWh，最终调整购电量23041510.3033 kWh，紧急购电97658.3186 kWh。计划费14599625.6047元，调整相关费用385639.6737元，紧急费567346.5000元，总费用15552611.7784元。

只使用0:00预报时总费用17242490.3682元。加入6:00、12:00、18:00更新后的节省为1689878.5897元，即9.8007%。逐步加入三个时刻的边际节省分别为679792.5948元、591585.4668元和418500.5281元。各策略12月31日末SOC相同，因此比较不受终端库存差异驱动。

## 10. 是否需要其他预报时刻

当前数据和结算口径下，6:00、12:00、18:00的边际节省均为正，均应纳入滚动策略。6:00和12:00主要利用白天光伏预报更新；18:00以后光伏接近零，其收益主要来自在新时点根据实际SOC重算晚间购电，而不是夜间光伏预测本身。因此论文应把“新预测信息价值”和“状态反馈重优化价值”区分表述。

## 11. 正确性检查

- 交付334天、每天144个计划值和144个最终调整值；
- 所有功率到电量均乘1/6；
- SOC范围1200—10800 kWh，跨时段与跨日连续；
- 单时段充放电互斥，功率均不超过5000 kW；
- 供需平衡、SOC状态转移和三类费用逐时复算；
- 预报发布时间不晚于对应时段开始时刻；
- Excel四个工作表与原模板名称、表头和日期位置一致；
- 完整数值以结果CSV、JSON为准。
