# 问题3：基于光伏滚动预报的微网购电调度

本次新增求解：按用户提供的“预报误差分析—日前计划—日内MPC—费用对照”思路，建立并运行全年滚动MILP。详细数值、指定四天的表1—表3和图像见[结果报告](结果/问题3结果报告.md)，提交表为[结果/result3.xlsx](结果/result3.xlsx)。

## 1. 问题分析与方案定位

问题2每天0:00只根据历史数据预测负载和光伏，制定一天的购电计划。问题3额外给出0:00、6:00、12:00、18:00发布的未来24小时整点光伏预报，并允许日内调整购电量。因此采用“每次发布预报时重新求解，先执行下一段，再用真实储电量继续优化”的模型预测控制（MPC）框架。

负载仍使用第二问已生成、经信息时点审计的按日类型XGBoost日前预测。光伏改用附件3的预报。使用第二问负载预测，不使用其购电量、储能状态或光伏Ridge预测作为第三问输入。四次滚动之间，实际储能执行因果反馈规则，并按真实缺口计算紧急购电。

本模型是带历史误差缓冲的确定性滚动MILP；没有构造完整场景树，因此不称其为求得全局最优的多阶段随机规划。

## 2. 时间、数据与信息集

### 2.1 统一时段和单位

每天144个时段，$\Delta t=1/6$小时。第$t=0,\ldots,143$段为$[t\Delta t,(t+1)\Delta t)$，主表用结束时刻标记。例如slot=0对应00:00—00:10，最后一段23:50—24:00归当天。

原始负载、光伏是kW，电价是元/kWh。优化变量全部采用kWh，$L_t=P_t^{load}\Delta t$，$V_t=P_t^{pv}\Delta t$。5000kW功率上限换算为单段$\bar E=5000/6$kWh。储电量$S_t$直接使用kWh，不再乘时间。图中的功率由电量除以$\Delta t$得到。

### 2.2 预报发布时间与目标时间分别索引

记$\tau_k$为预报发布时间，$h=1,\ldots,24$为提前小时数，则第$h$小时预报对应$\tau_k+h$，不能把各行的“预报1小时”都视作当天1:00。

例：6月21日18:00发布的第1小时预报对应当天19:00，第7小时对应6月22日1:00，第24小时对应6月22日18:00。所有对齐通过绝对时间戳完成，原始解析只用公共代码已输出的整点长表。

预报在$h=1,\ldots,24$的整点间线性插值；$h=0$锚点取发布时刻刚结束区间的已观测光伏功率。首次1月1日0:00无前一观测，按夜间光伏0处理。然后采样每个未来10分钟区间的结束时刻，作为该区间平均功率的近似。原始整点必须原值保留；插值不使用预报发布以后出现的实际值。

决策信息集包括：截至发布时间已结束的负载、光伏和实际SOC；当天0:00发布的负载预测；本次及更早发布的光伏预报；固定电价和原计划。程序不使用主表中的单一`pv_forecast_q3_latest_kw`字段重建历史预报，因为它不能表达某个旧发布时间的信息集。

### 2.3 跨日展望与初始状态

每次求解未来24小时。日内窗口跨到次日的部分仅用于储能展望：次日负载以当前日0:00已发布曲线的同钟点值延拓，次日普通购电量为内部暂定值，既不写入当天调整表，也不提前结算。到次日0:00重新形成次日原计划。

全年从2025年1月1日0:00的6000kWh连续运行。1月为热启动，正式表格只输出2月1日至12月31日334天。2月1日初始SOC来自1月31日实际末状态，不重置为6000。12月31日窗口在数据末端截短，不虚构2026年实测数据。

## 3. 预测误差与风险缓冲

采用净负荷误差而非单独光伏误差定义购电缺口：

$$\hat n_{t|k}=\hat P^{load}_{t|k}-\hat P^{pv}_{t|k},\qquad
\epsilon_{t|k}=(P^{load}_t-P^{pv}_t)-\hat n_{t|k}.$$

正误差意味着实测净负荷比预测更高。过去28天同一发布时间、同一提前时距的、已经全部观测完的误差，形成历史集$\mathcal H_k$。排除首日零预测的冷启动误差。风险缓冲为：

$$R_{t|k}=\min\{5000,\max[0,Q_{0.8}(\epsilon_{t|k};\mathcal H_k)]\}\quad(\mathrm{kW}).$$

例如今天6:00可使用昨天6:00所发布、到今天6:00已完全结束的24小时预报误差；不能使用今天6:00之后才实现的误差。样本少于28天则使用已积累样本；无历史时取0。

0.8是预先固定的风险参数。另比较0（不加缓冲）、0.7、0.9作敏感性分析，不按全年测试结果回选主参数。未假定正态分布，未把0.8解释为全天联合供电可靠率。

误差分析使用$\mathrm{MAE}=\frac1m\sum|\epsilon_i|$和$\mathrm{RMSE}=\sqrt{\frac1m\sum\epsilon_i^2}$。光伏预报单独评估，按发布时间和0—6、6—12、12—18、18—24小时的提前时距分组。比较新旧预报时额外固定相同目标时段，避免不同夜间占比造成误判；全年实测值只用于事后评估，不参与当日决策。

## 4. 模型建立

### 4.1 符号

| 符号 | 含义 | 单位 |
|---|---|---|
| $q_t^0$ | 当天0:00制定的原计划购电量 | kWh |
| $q_{t|k}$ | 第$k$次滚动后的购电量 | kWh |
| $q_t^*$ | 时段$t$最终生效的普通购电量 | kWh |
| $a_{t|k}^+,a_{t|k}^-$ | 相对原计划的上、下调量 | kWh |
| $c_{t|k},d_{t|k}$ | 规划充、放电量，均按交流侧计 | kWh |
| $S_{t|k}$ | 规划时段开始的储电量 | kWh |
| $z_{t|k}$ | 充电状态二元变量 | 0或1 |
| $u_{t|k}$ | 风险负荷的规划缺口松弛量 | kWh |
| $e_t$ | 实际执行时的紧急购电量 | kWh |
| $p_t$ | 附件1固定电价 | 元/kWh |

规划缺口$u$与实测紧急购电$e$严格区分：前者是优化中的风险代理，后者才进入实际账单。二者不必相等。

### 4.2 实际结算目标与原计划基准

题面“总费用包括计划购电费用、紧急购电费用和调整相关费用”按原计划全额支付解释：

$$C=\sum_t p_tq_t^0+\sum_t p_t\left[1.5(q_t^*-q_t^0)_++0.5(q_t^0-q_t^*)_+\right]
+\sum_t5p_te_t.$$

其中$(x)_+=\max(x,0)$。若电价为1元/kWh，计划100、调整至120，则费用为100+1.5×20=130元；计划100、调整至80，则为100+0.5×20=110元，均另加紧急费用。并非把全部调整后电量按1.5倍结算。

原计划$q^0$全天固定。6、12、18点各版本均与$q^0$比较，执行到一个时段时，只按该时段最后生效版本结算一次；未执行的中间展望不重复收费。本实现未另加题面未给定的固定调整次数费用。

由于供能约束是“不低于”，允许弃余电，而原计划费用又不退还，保持$q=q^0$能够替代任何$q<q^0$而不增加供能困难，还免去违约费。因此下调在该计费口径下被支配，最优解下调为零。这一性质已数值验证。若另有“退还原计划费用”规则，必须重新建模结算，不能与当前结果混用。

### 4.3 每次滚动的优化目标

窗口$\mathcal W_k$包含$N_k\le144$个10分钟时段，序号为$0,\ldots,N_k-1$，不会多取一个端点。令$\mathcal A_k$为尚未执行但已有当日原计划的部分，$\mathcal F_k$为无原计划的次日暂定部分：

$$\min J_k=\sum_{t\in\mathcal A_k}p_t(1.5a^+_{t|k}+0.5a^-_{t|k})
+\sum_{t\in\mathcal F_k}p_tq_{t|k}+\sum_{t\in\mathcal W_k}5p_tu_{t|k}.$$

0:00新制定原计划时，整个当日窗口按$\sum p_tq^0_t+\sum5p_tu_{t|0}$优化；日内原计划费用已是常数，不能再作为可改变的普通购电费用重复计算。实现附加$10^{-7}\sum(c+d)$数值择优项减少等价循环，该项不进入实际费用。

### 4.4 供能、储能与调整约束

供能量不低于风险修正负载：

$$q_{t|k}+u_{t|k}+d_{t|k}-c_{t|k}\ge(\hat n_{t|k}+R_{t|k})\Delta t.$$

它允许多余能量，不能用不含弃电变量的等式替代。需要核对物理守恒时，可以显式加入非负弃余电变量，将其从供给侧扣除再写等式。

储能效率与电量动态：

$$S_{t+1|k}=S_{t|k}+0.9c_{t|k}-\frac{d_{t|k}}{0.9},\qquad1200\le S_{t|k}\le10800.$$

$$0\le c_{t|k}\le\frac{5000}{6}z_{t|k},\quad
0\le d_{t|k}\le\frac{5000}{6}(1-z_{t|k}),\quad z_{t|k}\in\{0,1\}.$$

初始状态取当前实测值$S_{0|k}=S_k^{real}$。为减轻窗口末端透支储能，加入$S_{N_k|k}\ge6000$的规划终端参考约束，并测试3600、8400kWh的敏感性。**这是建模假设，不是题目第三问要求每天首末SOC相等。**实际末状态不强制达到6000，也不手动重置。

当日调整满足

$$q_{t|k}-q_t^0=a^+_{t|k}-a^-_{t|k},\qquad q_{t|k},u_{t|k},a^+_{t|k},a^-_{t|k}\ge0.$$

正电价使最优解中的上下调不会同时为正。目标与约束均线性，只有充放电状态是二元变量，因此是MILP，使用SciPy接口调用HiGHS求解。

## 5. 滚动执行与误差回放

1. 0:00用当前信息求解24小时模型，保存完整$q^0$。
2. 正式四次预报方案先执行未来6小时；6、12、18点用新预报和真实SOC求解新的24小时窗口，各执行下一段6小时。
3. 每10分钟，仅观察当前区间实际净负荷。若普通购电与光伏有余量，优先在功率和容量限制内充电，其余计为弃余电；若有缺口，优先放电，剩余部分紧急购电。
4. 以交流侧电量计算实际SOC动态，实际末状态传递到下一段、下一天。
5. 次日0:00再次制定新原计划。全年费用只汇总正式区间真实执行的三类费用。

具体地，$v_t=q_t^*-(P_t^{load}-P_t^{pv})\Delta t$。若$v_t\ge0$，$c_t=\min\{v_t,5000/6,(10800-S_t)/0.9\}$，剩余$v_t-c_t$弃用；若$v_t<0$，$d_t=\min\{-v_t,5000/6,0.9(S_t-1200)\}$，$e_t=-v_t-d_t$。这是预先固定的实时反馈规则，优化得到的储能轨迹是计划参考而非强制执行值。

采用区间平均功率建模，假设区间内控制可以观测并补足净缺口。未假装在制定日前或日内购电量时已知道未来10分钟的实测平均功率。

## 6. 求解结果与解释

主方案（风险分位数0.8，规划终端参考6000kWh，四次滚动）完成1460次滚动求解，正式334天结果为：

| 项目 | 数值 |
|---|---:|
| 计划购电费 | 13,461,929.89元 |
| 调整相关费用 | 256,551.71元 |
| 紧急购电费 | 173,776.57元 |
| 总购电费 | 13,892,258.17元 |
| 紧急购电量 | 29,380.23kWh |
| 2月1日实际初始储电量 | 7,827.28kWh |
| 12月31日实际末储电量 | 6,213.98kWh |

同样使用附件3的0:00预报、同样参数和同样2月1日初始状态，只制定日前计划的对照总费用为13,948,842.11元，紧急购电77,004.88kWh。四次滚动节省56,583.94元（约0.41%），紧急购电显著减少。此处对照不是只允许附件1—2的第二问，不能把附件3优势错误归因于MPC本身。

八种预报时刻组合的回放中，0:00+18:00组合的总费用低于四次滚动，但紧急购电高于四次滚动，说明“预报更新更频繁”不自动等于“费用最低”。同样，0.7风险参数在本数据的敏感性实验中费用更低，但0.9紧急购电更少。应区分费用与风险取舍，不能只按RMSE或更新次数作结论，也不能把全年回放中最便宜的组合说成事前已知最优。

## 8. 模型评价与可扩展内容

优点：统一能量单位；明确发布时间与目标时间；实际SOC反馈和跨日递推；原计划与调整费用不会重算；模型约束与实际回放均可独立复核；通过相同预报与初始状态的对照隔离滚动价值。

局限：末端参考和风险分位数是工程参数；采用单路径风险缓冲而非全场景概率建模；实时储能反馈未显式优化未来应急价值；次日负载延拓较简单；未计题目没有给出的退化、并网购电上限或固定调整费用。求解器最大MILP间隙约$9.34\times10^{-8}$，仅证明各次所建MILP的数值求解精度，不证明全年随机策略全局最优。

下一步问题4可复用时间、储能和计费框架，但必须单独规定波动电价的可知信息及预测方法，不能把附件4未来实测电价直接当作事前已知。本次未求解问题4。
