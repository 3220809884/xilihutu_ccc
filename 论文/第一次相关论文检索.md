# C 题第一次相关论文检索

## 检索说明

本轮从 IEEE Xplore、ScienceDirect、中文期刊官网、MDPI、Wiley 等公开学术入口中筛选 8 篇与本题最相关的论文。筛选重点是：并网微网、光伏与储能、购电成本、日前计划、预测误差、日内滚动调整以及波动电价。

关联度是与本题解答结构的匹配分，不代表论文质量或引用影响力。评分主要考虑系统构成、优化方法、信息时序、费用规则和模型可迁移性。

## 首轮阅读优先级

- 第一优先：[1]–[5]，用于建立和核对问题 1–3 的核心结构。
- 第二优先：[6]–[8]，用于问题 4、预测误差和滚动预测价值分析。

现有《参考文献候选.md》中的负荷预测论文 Taylor 与 McSharry（2007）、无外生变量光伏预测论文 Pedro 与 Coimbra（2012），仍分别作为负荷预测和光伏预测的优先文献，本次不重复占用 8 篇名额。
