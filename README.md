# 2026 数学建模国赛 C 题项目

本项目研究含小区负载、光伏、储能和外部电网的微网购电调度。团队统一使用每天 144 个 10 分钟时段。

## 目录

- 题目：原始题目与附件，只读
- 公共代码：数据读取、时间轴、校验和公共模型函数
- 问题1 至 问题4：各问的建模笔记、代码和结果
- 论文：公式、论文草稿、图表和最终 LaTeX
- 参考资料：经核实的论文和补充资料

## 统一数据处理规则

公共代码中的 build_master_table.py 将附件 1–4 统一为每天 144 行的主表：

- 一行对应一个日期和一个 10 分钟时段；
- time_end 是区间结束时刻：00:10、00:20、……、24:00；
- 负载和光伏功率保留为 kW；
- 电价保留为元/kWh；
- 建模代码调用 to_energy(power_kw) 后才把功率乘以 1/6 小时转换为 kWh；
- 附件 3 的原始整点预测单独保存，并按发布时间和目标时刻生成滚动预测列。

运行：

    python3 公共代码/build_master_table.py

输出：

    公共代码/数据/master_10min.csv
    公共代码/数据/forecast_attachment3_hourly.csv

master_10min.csv 是问题 1–4 共用的主表。任何问题的代码不得自行重新解析附件时间列。

## 环境

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt

建议使用 Python 3.10 或更高版本。求解器优先使用 scipy.optimize.milp。

## 工作顺序

1. 运行公共数据处理并检查每天 144 个时段。
2. 完成问题 1 的单日 MILP。
3. 加入问题 2 的逐日预测、紧急购电和跨日 SOC。
4. 加入问题 3 的 0:00、6:00、12:00、18:00 滚动更新。
5. 将价格替换为波动电价，完成问题 4。
6. 结果通过费用复算和 Excel 模板检查后，再填入论文。

原始附件不要覆盖。结果文件写入对应问题的结果目录。
