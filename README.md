# 2026 数学建模国赛 C 题项目

题目：微网与外部电网电力调控策略。

本项目按“题目 → 公共数据处理 → 问题 1—4 → 论文”的顺序组织。原始题目和附件位于 题目/，只读使用；模型代码、运行日志和结果分别放在对应问题目录；论文草稿位于 论文/。

## 当前已放入的内容

- 题目/：C 题 PDF、附件 1—4 和附件 5 的五个结果模板；
- 论文/建模公式初稿.md：统一符号、MILP/MPC 公式和待确认口径；
- 论文/论文框架初稿.md：可继续填入结果的论文 Markdown 骨架；
- 论文/参考文献候选.md：已核实的候选文献；
- 团队快速上手指南.md：环境、分工、时间单位和结果校验说明；
- 论文/主要符号.csv：团队统一使用的符号表。

## 统一约定

1. 附件中的负载和光伏是 kW，决策变量和结果文件中的购电、充电、放电是 kWh；10 分钟电量等于功率乘 \(1/6\) 小时。
2. 供电约束使用“\(\ge\)”；允许多余光伏或计划电未被完全利用。
3. 计划购电费按照计划量结算；紧急购电按照交易时刻电价的 5 倍结算。
4. 问题 2—4 的 SOC 跨日递推，不能每天重置为 6000 kWh。
5. 附件 3 的“预报 \(h\) 小时”对应“发布时间 + \(h\) 小时”，不能按当天固定列号错位。
6. 结果文件必须复制模板后填写，不能修改原始模板的工作表名和表头。

## 建议运行顺序

1. 公共代码完成日期、时段和单位检查；
2. 问题 1 建立并验证基础 MILP；
3. 问题 2 加入历史预测、紧急购电和跨日 SOC；
4. 问题 3 加入 0:00、6:00、12:00、18:00 滚动 MPC；
5. 问题 4 将固定价格替换为附件 4 的日期—时段价格；
6. 用独立校验程序检查电量平衡、SOC、费用和模板格式；
7. 将有结果支撑的数字填入 论文/论文框架初稿.md，确认后再生成 LaTeX。

## 环境

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-c题.txt
~~~

推荐使用 Python 3.10+、scipy.optimize.milp 和 openpyxl。论文定稿阶段再配置 XeLaTeX。

## 团队协作

建模组只修改各问题的 建模笔记.md 和公式相关文件；编程组将代码放在各问题的 代码/；结果放在各问题的 结果/；论文组只使用已核验的代码结果填表和写结论。任何新假设都要同步写入论文和建模笔记。
