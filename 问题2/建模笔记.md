# 问题 2 建模笔记

## 1. 问题目标

每天0:00提交当天144个10分钟时段的计划购电策略。计划电按计划量全额结算，实际供电缺口按同时段电价的5倍紧急补购。以计划费与紧急费之和评价策略。

## 2. 当前时刻可用信息

使用附件1固定日内电价，以及附件2中目标日之前已经完成的负载、光伏观测。预测函数仅接受历史前缀；不读取附件3、附件4，也不把当天未来实际量当作已知预测。实时执行仅使用当前时段供需差与当前SOC。

## 3. 数据与时间范围

统一读取 `公共代码/数据/master_10min.csv` 的 `date`、`slot`、`time_end`、`price_fixed_yuan_per_kwh`、`load_actual_kw`、`pv_actual_kw`。内部slot=0表示00:00—00:10，slot=143表示23:50—24:00。

完整状态轨迹为2025年1月1日至12月31日；按题目附录2，Excel交付范围为2月1日至12月31日，共334天、48096个计划值。指定日期为3月20日、6月21日、9月23日、12月21日。

## 4. 参数和变量

功率变量均为kW，储电量S为kWh，Δt=1/6小时。充、放电效率各0.9；充、放电接口功率上限各5000 kW；1200≤S≤10800；2025年1月1日0:00初值6000 kWh。模型包括计划购电q、充电c、放电d及二元模式z。实际执行另记录紧急购电e和未利用富余功率w。

## 5. 模型假设与历史预测

直接预测净负荷N=L−PV。对每个时段，取此前W个完整日同期净负荷的α经验分位数（线性插值）。以1月15—31日为顺序验证期，比较W∈{7,14,28}与α∈{0.50,0.65,0.80,0.90,0.95}的15组组合。评分为计划费+紧急费+(6000−验证末SOC)×最低电价/0.9。最后一项只用于选参，不计入正式费用。

选出W=14、α=0.65，2月1日0:00冻结参数。每日样本更新只使用已完成日期。1月1日无历史时采用零计划、储能静置，缺口紧急补购；1月2—31日以预先固定的W=14、α=0.80运行。参数验证使用虚拟轨迹，不改变已执行的1月轨迹。

计划日末SOC目标设为6000 kWh，作为有限时域的储备假设，并非问题二强制条件。实际日末SOC不重置，实际末值传给下一日。当前10分钟时段的代表功率被视作实时可测，储能可按该功率执行。未考虑设备退化成本和售电。

## 6. 目标函数

日前MILP：`min Σ π[t] q[t] Δt`，供需约束使用风险调整预测。闭环评价费用：`Σ π[t] q[t] Δt + Σ 5π[t] e[t] Δt`。α通过1月闭环费用选择，把提前购电和紧急风险的权衡纳入策略。

## 7. 约束与实时执行

    q[t] + d[t] - c[t] >= N_hat[t]
    S[t+1] = S[t] + 0.9*c[t]*Δt - d[t]*Δt/0.9
    1200 <= S[t] <= 10800
    0 <= c[t] <= 5000*z[t]
    0 <= d[t] <= 5000*(1-z[t]), z[t] ∈ {0,1}
    S[0] = 当天实际初始SOC，S[144] = 6000

实际执行固定q。当b=q+PV−L≥0时，`c=min(b,5000,(10800−S)/(0.9Δt))`，d=e=0，未利用部分计入w。当b<0时，`d=min(−b,5000,(S−1200)*0.9/Δt)`，c=0，e=−b−d。紧急电只补剩余缺口。单时段充放电互斥。

## 8. 求解方法和复现

`代码/solve_q2.py` 使用SciPy的HiGHS MILP，相对间隙1e-9，单次时限30秒，求解失败即终止。当前结果由SciPy 1.18.1产生。安装项目requirements中的NumPy、pandas、SciPy、openpyxl后，在项目根目录运行：

    python 问题2/代码/solve_q2.py
    python 问题2/代码/report_q2.py
    python 问题2/代码/verify_q2.py --replay

求解程序更新CSV、JSON；Excel由 `代码/export_q2.mjs` 使用 `@oai/artifact-tool` 填充原模板，运行时将NODE_PATH指向已安装的该包所在node_modules目录，将Q2_PREVIEW_DIR设为临时预览目录，然后运行 `node 问题2/代码/export_q2.mjs`。求解后需先导出Excel再执行完整验证。导出器保留原表名、日期和时段标签。

## 10. 可行性与正确性检查

`代码/verify_q2.py` 独立对照附件1、附件2原始数值，复算供需平衡、SOC状态转移、跨日连续性、功率上限、充放电互斥、计划与五倍紧急费用，按严格历史前缀重建每日预测，并逐单元格核对Excel计划、四小时充放电和紧急事件。`--replay` 还重求全年日前MILP及全部15组1月候选，不覆盖结果。

## 11. 本问结果与局限

2—12月计划购电23104822.1797 kWh，紧急购电481243.1598 kWh；计划费14385823.8605元，紧急费2993856.1730元，总费17379680.0335元。2月1日实际初SOC为10800 kWh，12月31日末为5822.0969 kWh。全年无同时充放电，实际SOC保持在1200—10800 kWh，跨日连续。

每天的MILP仅对给定风险预测和末端储备目标求最优；完整预测与反馈策略不声称是随机动态控制全局最优。历史分位数可能受季节变化影响；当前实时规则优先避免当下紧急购电，未优化未来储能机会成本。未来可研究终端目标、分位数和反馈规则的敏感性。
